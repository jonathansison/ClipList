# ClipList

A lightweight Windows desktop checklist and screenshot notepad built with Electron.

## Features

- Multi-tab checklists (double-click any tab to rename)
- Checkboxes, bullet points, and numbered lists
- Paste screenshots directly (`Ctrl + V`) and click to view full-size
- Dark & Light theme toggle
- Saves your notes automatically on your PC

## Download (Windows)

Go to the **[Releases](https://github.com/jonathansison/ClipList/releases)** page and download:

- **`NoteList 1.0.0.exe`** (runs right away, no install needed)
- **`NoteList Setup 1.0.0.exe`** (standard Windows installer)
